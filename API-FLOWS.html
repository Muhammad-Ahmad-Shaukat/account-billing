8. Empty field policy (invoice webhook payload)

Field group If empty / null / missing Result
shopify_customer_id, invoice_number, revision Rejected 400 — not stored
subtotal, total_tax, total_amount, less_payment, amount_due Still stored 202 — downloadable: false
PO, salesperson, addresses, order id, freight qty/price, etc. Allowed 200 — stored normally
Same invoice_number + same revision again Rejected 409 — exists: true
